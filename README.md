# Check_ip
Консольное приложение для проверки IP адресов через API ipinfo.io

## Требования
- .NET SDK 6.0 или выше
- Пакет Newtonsoft.Json

## Как запустить
1. Склонировать репозиторий
2. Открыть терминал в папке проекта
3. Выполнить команды:
     dotnet restore
     dotnet run

## Что делает программа
- Читает IP адреса из файла IPs.txt
- Проверяет каждый IP через API ipinfo.io
- Выводит статистику по странам и количество IP для каждой
- Определяет страну с максимальным количеством IP
- Выводит города для этой страны

## Содержимое проекта
- **Program.cs** - основной код программы
- **IPs.txt** - список IP адресов для проверки
- **IpChecker.csproj** - конфигурационный файл проекта

## Структура кода
Программа состоит из:
- Класса `IpData` для хранения информации об IP
- Функции `GetIpInfo()` для запроса к API
- Основной логики в `Main()` для обработки и вывода результатов

## Ограничения
- Используется только пакет Newtonsoft.Json
- Все значения вычисляются программно
- Между запросами к API добавлена задержка 500 мс
